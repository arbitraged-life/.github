# Retired repository

Organization profile, inherited community defaults, workflow templates and
account-wide settings automation are discontinued.

Reusable engineering assets now belong to
[agent-platform](https://github.com/arbitraged-life/agent-platform). Its documented
workflows are consumed at immutable revisions. Environment-specific operations
are maintained separately in private configuration.

This repository retains Git history as migration evidence. Its old workflows and
helpers are retired, with no forwarding workflows. Historical code is not a
supported installation or deployment source.
